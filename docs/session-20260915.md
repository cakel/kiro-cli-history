### 4. install 시 버전 자동 주입 구현
- **문제**: install 스크립트가 git hash만 주입, VERSION 상수는 하드코딩 의존
- **해결**: `_BUILT_VERSION` 변수 추가 + install.ps1/install.sh에서 `git describe --tags --abbrev=0`으로 태그 주입
- 이후 태그만 만들면 VERSION 상수 수동 업데이트 불필요
- 정상 설치 시 표시: `v0.1.0-cakel.3-<hash>`
