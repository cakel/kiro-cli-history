# 2026-10-02 작업 메모

## 오늘 작업 범위

대규모 UX/기능 개선. 주요 항목:

---

## 1. 디렉토리 없을 때 Resume 다이얼로그 (`MissingDirScreen`)

- `Ctrl+R` 누를 때 세션의 원래 디렉토리가 없으면 error notify 대신 선택 다이얼로그 표시
- 옵션: **Create Directory** (원래 경로 생성) / **Use Current Dir** / **Cancel**
- `widgets.py`: `MissingDirScreen` 추가

---

## 2. Path 입력창 분리 (`#path-input`)

- 기존 단일 검색창 → 텍스트 검색 (`#search-input`) + 경로 필터 (`#path-input`) 분리
- `_get_filtered_base()`에 path substring filter 추가
- CLI 인자: `kiro-cli-history .` → 현재 디렉토리를 path input에 자동 입력
- `_ko_to_qwerty()` 구현 (두벌식 역매핑) — 검색창에서는 미적용, 내비게이션 키만 처리

---

## 3. Days Span + Retention Days

- 앱 시작 시 세션 날짜 범위 계산 (`_calc_span_days`) — aware/naive datetime 정규화 처리
- `config.py` DEFAULT_SETTINGS에 `retention_days: 90` 추가
- status bar: `N sessions | Xd history`
- 시작 notify: `"N sessions loaded | spanning X days | retention: 90d"`

---

## 4. SQLite → Archive 동기화

- `sync_sqlite_to_archive()`: SQLite 세션을 `archive/<id>.json`으로 export
- `retention_days` 초과한 `.json` → `.json.gz`로 압축, 원본 삭제
- `get_sessions()`에 archive 소스 병합 (dedup)
- archive 세션 lazy search 지원

---

## 5. ripgrep 통합 (선택적)

- `_rg_available()` + `_rg_path()`: 번들 바이너리 우선, PATH fallback
- `_rg_find_in_dir()`: 토큰별 rg 실행 후 교집합 (AND semantics)
- cold-cache JSONL 검색, `.json.gz` archive 검색에 rg 사용
- `bin/` 디렉토리에 5개 플랫폼 rg 바이너리 사전 다운로드:
  - `windows-x64/rg.exe` (14.1.1)
  - `macos-arm64/rg`, `macos-x64/rg`
  - `linux-x64/rg`, `linux-arm64/rg`
- `install.ps1` / `install.sh`: 다운로드 대신 `bin/` 에서 복사

---

## 6. 키보드 단축키 전면 개편

### 새 단축키
| 키 | 동작 |
|----|------|
| `?` | 오른쪽 키 도움말 패널 토글 (`KeysHelpScreen`) |
| `p` / `ㅔ` | path filter 포커스 |
| `m` / `ㅡ` | preview 페이지 다운 |
| `M` | preview 페이지 업 |
| `Alt+N` | 선택 세션을 새 디렉토리에서 resume |
| `Ctrl+X` | 선택 세션 export (.json.gz) |
| `Ctrl+Del` | 선택 세션 삭제 (확인 다이얼로그) |
| `Ctrl+Q` | 앱 종료 |

### 변경
| 키 | 변경 전 | 변경 후 |
|----|---------|---------|
| `Ctrl+N` | 현재 디렉토리 새 세션 | 즉시 새 세션 (다이얼로그 없음) |
| `Esc` | 단계별 클리어→종료 | 검색/경로 동시 클리어 (종료 안 함) |

### 한국어 IME 동치키 (두벌식)
- `ㅔ` → `p` (path 포커스)
- `ㅓ` → `j` (목록 아래)
- `ㅏ` → `k` (목록 위)
- `ㅡ` → `m` (preview 페이지 다운)
- `ㅗ` → `h` (목록 포커스)
- `ㅣ` → `l` (preview 포커스)

## 10. 버그 수정

| 버그 | 원인 | 수정 |
|------|------|------|
| `TypeError: can't compare offset-naive and offset-aware datetimes` | `_calc_span_days`에서 JSONL(aware) + SQLite(naive) datetime 혼합 | `.replace(tzinfo=None)`으로 naive UTC 정규화 |
| crash 로그 미기록 | `init_logging`이 debug=False 시 파일 미오픈 | 항상 파일 열기, ERROR는 항상 기록 |
| `_load_sessions_async` 예외 미포착 | try 블록이 `get_sessions()`만 감쌈 | `_load_sessions_body()`로 분리 후 전체 감싸기 |
| 디렉토리 없을 때 resume crash | `os.chdir` 전 존재 확인 없음 | `os.makedirs` 추가 |
| `#path-input` / `#search-input` 겹침 | 두 input 모두 `dock: top` | `dock` 제거 |
